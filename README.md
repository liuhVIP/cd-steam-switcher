# 红沙版本切换器

面向 Windows 的 Crimson Desert 历史版本下载、替换与锁定工具。

## 使用

1. 解压发布包。
2. 双击 `启动红色沙漠版本切换器v1.0.bat`。
3. 选择历史版本和下载盘符。
4. 在 Steam 控制台执行工具复制的 `download_depot` 命令。
5. 下载完成后选择安装并锁定。

如果 Steam 显示仍在更新或需要恢复最新版，可在菜单选择 `9) 解除 Steam 更新状态`。工具会先备份当前 ACF，再写入内置最新版本信息；完成后请完全退出并重新启动 Steam。

下载缓存默认保留；安装完成后可按提示选择是否删除。
